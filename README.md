# TEMPOLIVE 連線節拍器

**把節拍、歌單與樂團溝通，放在同一個畫面。**

TEMPOLIVE 是為教會敬拜團、現場樂團與音控同工設計的網頁節拍器。可以用來個人練習、準備排練歌單，也能建立團隊房間，由主持人統一控制節奏，搭配 **live傳話** 向指定樂器發送語音提醒。

採用 **HTML、CSS 與原生 JavaScript**，完整功能收在單一 HTML 檔，不需要安裝套件或執行建置指令。介面使用繁體中文，支援手機與電腦版面。

[功能特色](#功能特色) · [快速開始](#快速開始) · [歌單與設定](#歌單與設定) · [部署](#部署) · [注意事項](#注意事項)

> 個人節拍器與小遊戲可在檔案載入後離線使用；團隊房間及 live傳話需要網路。目前使用公開測試中繼，適合先試用與排練，不保證零延遲或不中斷。

## 功能特色

| 功能 | 說明 |
| --- | --- |
| **節拍控制** | 40–300 BPM、點按測速、四分／八分／十六分音符，支援重音、一般拍與靜音。 |
| **現場歌單** | 儲存歌名、速度、拍號及預備拍，快速切換前後首，支援排序與 JSON 匯入／匯出。 |
| **團隊房間** | 以四位數字加入房間，由主持人控制共同節奏；各裝置可自行調整音量、音色與時間校正。 |
| **live傳話** | 選擇樂器或全部人，再點短句，自動送出並收起面板；支援中文語音與自訂訊息。 |
| **音訊與視覺** | 五種音色、標準／加強輸出、深淺色模式、專注模式，以及節拍器區塊內的螢光提示。 |
| **節奏小遊戲** | 聽示範、記節奏、敲出來，提供漸進關卡、最高分紀錄、繼續遊玩與重新挑戰。 |

## 快速開始

### 個人練習

1. 下載 [`TEMPOLIVE-v1.17.html`](./TEMPOLIVE-v1.17.html)，使用完整瀏覽器開啟。
2. 選擇 BPM、拍號與音符細分，點選拍點設定重音，再按 **「開始節拍」**。
3. 使用主畫面的音量滑桿調整聲音；其他選項位於右上角 **「設定」**。

不需要另外下載音檔或小遊戲檔案。請避免只在通訊軟體的檔案預覽中操作。

### 團隊合奏

1. 主持人按 **「建立房間」**，選擇樂器／角色，將四位數字代碼交給團員。
2. 團員開啟相同版本，按 **「代碼加入」**，選擇樂器／角色並輸入代碼。
3. 完成連線與校時後，由主持人控制播放及節奏。使用傳話前，每台裝置先按 **「試聽語音」**。

房間最多 **12 人，包含主持人**。分享的是目前歌曲、節奏與播放狀態，不會同步或覆蓋團員的整份歌單。

**藍牙是各裝置的音訊輸出方式，不是房間連線方式。** 團隊成員仍須連上網路。

## 節拍器操作

支援拍號：**2/4、3/4、4/4、5/4、6/8、7/8、12/8**。BPM 固定以四分音符為基準，預備拍可選擇關閉、1 小節或 2 小節。

點選拍點可循環切換 **重音 → 一般 → 靜音**。播放中調整 BPM、拍點及音符細分會立即更新；切換歌曲則安排在小節交界。已交給裝置輸出的聲音無法回收，實際聽感仍受音訊緩衝與網路延遲影響。

右上角提供 **專注模式、疑問教學、節奏小遊戲、設定**。音量、靜音與下一首保留在主畫面，方便現場操作。

| 快速鍵 | 功能 |
| --- | --- |
| 空白鍵 | 播放／停止；房間參與者則操作本機收聽或聲音恢復。 |
| `T` | 點按測速。 |
| `N` | 下一首。 |
| `↑` / `↓` | 速度增減 1 BPM，搭配 Shift 增減 5 BPM。 |
| `F` | 切換專注模式。 |

輸入文字或開啟對話視窗時，不會套用一般主畫面快速鍵。

## 歌單與設定

### 先準備歌單，現場直接切換

每首歌曲可儲存歌名、BPM、拍號、音符細分與預備拍，支援新增、編輯、排序、刪除及前後首循環切換，最多保留 200 首。

在主畫面臨時改了速度，希望更新該首歌曲的預設時，使用：

**儲存目前設定 → 確認歌曲資料 → 儲存歌曲**

### 切歌保留目前的輕重音

v1.17 切換歌曲時，會更新歌曲的速度、拍號、細分與預備拍，**但不會把目前的輕重音設定重設**。

全部重音或全部一般拍會延續到下一首；混合設定則依拍點位置保留。拍數變少時，暫時隱藏的拍點仍會記住，之後增加拍數就能恢復。從未設定過的新拍點使用一般拍。

例如：**重、一般、靜音、重** → 切成三拍 → **重、一般、靜音** → 再回四拍 → **重、一般、靜音、重**。

這項延續設定不會批次改寫已儲存的歌曲資料。

### 本機保存與備份

歌單、歌曲順序、目前節奏，以及音色、音量、深淺色與輕重音延續設定，會保存於目前瀏覽器。自訂樂器、常用短句、語音偏好與遊戲音量也有各自的本機保存設定。

**同一台裝置不一定使用同一份資料。** 更換瀏覽器、使用無痕模式、清除網站資料，或改用不同網站來源，都可能讀不到舊設定。直接開啟本機 HTML 時，換檔名或移動位置也不保證沿用原資料。

更新版本前，請先 **「匯出歌單」**。新版需要時再匯入；匯入會取代原有整份歌單，不是追加合併。歌單匯出只備份歌曲資料，並非所有裝置設定的完整備份。

## live傳話

建立或加入房間後，右側會出現跟隨畫面的 **「live傳話 NEW」** 側拉控制鈕。

**選對象 → 點短句 → 自動送出 → 返回主畫面**

可指定某個樂器，或選擇「全部人」。同樣樂器有多人時會以編號區分；「全部人」不包含發送者自己。選錯對象可返回重選，不需要傳送確認或接收回報。

內建角色包括 **鋼琴、鍵盤、木吉他、電吉他、貝斯、鼓、主領、歌唱、音控**，也能新增樂器。

常用短句包含 **太快、太慢、多一點、少一點、監聽大、監聽小、要幫忙**。「太快」會播報「慢一點」，「太慢」會播報「快一點」，例如：

> 鼓手說，鋼琴，快一點。

自訂訊息最多 40 字，可儲存為常用短句。收到訊息時會顯示文字，語音已啟用時自動播報，也可按「再播一次」。

傳話不會主動暫停、重啟或降低節拍器音量。**語音與節拍是否能在實際裝置上穩定同時播放，仍需先試聽確認。**

## 聲音與畫面

五種音色為 **木塊、清晰電子、牛鈴、短鈴、馬林巴**，預設馬林巴；輸出強度提供 **標準／加強**。

節拍器、live傳話與小遊戲的音量分開控制，彼此不會互相修改。藍牙耳機請先在系統配對；瀏覽器支援時可從設定選擇音訊裝置，否則由作業系統切換。

**「螢幕閃爍 NEW」** 位於深色模式下方，預設關閉。開啟後僅節拍器區塊內發光：淺色模式為黑色、深色模式為白色，每次約 0.32 秒，逐漸淡出。高速時會減少閃爍次數；對閃光敏感者請保持關閉。

## 節奏小遊戲

點選右上角的 **遊戲圖示 NEW**，先聽系統示範，再憑記憶敲出相同節奏。示範時按鍵不會自動閃動，玩家敲擊仍有回饋。

共 **10 關、3 次失誤機會**，每題 4 拍，準確率達 95% 即可通關。收起後再開啟，可選擇繼續目前進度，或重新遊玩；重新遊玩會保留最高分與遊戲音量。

未完成的一局只保留在目前頁面中，重新整理或關閉整個網頁後不會還原。遊戲不會替使用者停止主節拍器，要避免兩組節奏重疊，請先自行停止或靜音本機節拍。

## 部署

本專案是單檔靜態網頁。直接使用時只需要下載 HTML；發布到 GitHub Pages 時，可將正式使用的完整 HTML 複製為 `index.html`：

```text
TEMPOLIVE/
├── README.md
├── index.html              # 網站入口，內容為完整節拍器 HTML
└── TEMPOLIVE-v1.17.html     # 保留版本原始檔
```

在儲存庫 **Settings → Pages** 選擇 **Deploy from a branch**，指定存放檔案的分支與根目錄後儲存。詳細流程可參考 [GitHub Pages 官方部署說明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

GitHub Pages 只提供網頁檔案，**不會提供或取代房間中繼服務**。團隊功能仍依 HTML 內的中繼設定連線。

## 技術

| 用途 | 實作 |
| --- | --- |
| 介面 | HTML、CSS、原生 JavaScript，單一 HTML，無須 npm 或前端框架。 |
| 節拍發聲 | Web Audio API，本機合成音色與音訊時鐘排程。 |
| 團隊同步 | MQTT 3.1.1 over WSS，傳送節奏控制資料，各裝置自行產生聲音。 |
| 語音傳話 | Web Speech API，使用裝置提供的中文語音。 |
| 本機資料 | localStorage，歌單支援 JSON 匯入／匯出。 |
| 節奏遊戲 | 內嵌 iframe，獨立音訊環境與操作事件。 |

## 注意事項

**連線與隱私：**目前使用 shiftr.io 公開測試中繼，四位代碼是邀請碼，不是安全密碼。樂器、歌名、節奏與傳話文字會經過中繼；指定傳話也由主持人轉送，並非端對端加密，請勿傳送敏感資訊。

**聲音與同步：**網路校時不代表耳機實際出聲完全同步。藍牙、音效卡與系統排程都可能影響延遲；請保持頁面在前景，正式使用前以現場裝置、監聽設備及網路排練測試。出現「恢復本機聲音」時，可由中央按鈕重新啟用。

**語音輸出：**live傳話使用系統語音輸出，不會自動跟隨節拍器在網頁內另外選擇的音效卡。部分語音可能需要網路；第一次使用或切換裝置後，請先按「啟用／試聽」。

## 回報問題

可透過 Issues 回報操作問題或提出建議。請附上使用版本、手機／電腦型號、瀏覽器、重現步驟，以及是否使用藍牙、房間或語音功能；有錯誤提示時請提供完整文字。截圖與診斷資料請先移除不需要公開的房間代碼及訊息內容。

新增功能的入口使用 **NEW** 標示，並維持手機操作、深淺色與既有資料相容性。
